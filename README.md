# Personal productivity apps

Selected source modules from three personal macOS apps.

- **向光生长** — A JSON progress store with revision checks and snapshot history. Run its tests with `cd growth && python3 -B -m unittest`.
- **每日算法** — A dashboard component that unlocks a reward when 70% of the day's distinct tasks are complete. It uses the host app's task state and rendering helpers.
- **Canvas 小课岛** — A read-only Canvas client with pagination, rate-limit handling and bounded attachment downloads. The caller supplies a Canvas token at runtime.
